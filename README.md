# Playwright E2E Framework 🚀

A robust end‑to‑end testing framework built with **Playwright**, **Cucumber (BDD)**, and **Allure Reporting**.  
This project demonstrates automated UI and API testing with rich reporting and screenshots.

---

## 📂 Project Structure
- `features/` → Gherkin feature files (BDD scenarios)
- `steps/` → Step definitions mapping Gherkin steps to Playwright actions
- `supports/` → Hooks, world configuration, and test setup
- `pages/` → Page Object Models for UI interactions
- `utils/` → Utility functions (API calls, helpers)
- `reports/` → Generated Allure reports
- `allure-results/` → Raw Allure results (ignored in Git)
